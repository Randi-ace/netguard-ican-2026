关于净网护航

我们相信安全产品不该是「黑盒开关」，而应是可理解、可配置、可协作的家庭数字基础设施。

📡

平台介绍

净网护航将 DNS / 浏览器扩展 / 本地代理能力抽象为统一控制台，面向个人与家庭提供一致的安全策略。

🧭

产品背景

广告与诈骗形态快速演化，传统规则难以覆盖长尾威胁。我们以 AI 评分 + 专家规则双轨并行，降低误杀同时提升召回。

⚙️

技术说明

端侧轻量推理、云端大模型复核、差分隐私聚合统计——三层架构兼顾性能与隐私。

👥

核心成员来自浏览器内核、威胁情报与体验设计背景，坚持「安全可感知」的产品哲学。
